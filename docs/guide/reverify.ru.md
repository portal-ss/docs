# Реверификации

Реверификация — повторная проверка аккаунта, уже верифицированного через платформу, когда биржа снова её требует. Её проходит исполнитель первичной верификации.

## Типы

- **MEXC:** Face Security — повторная проверка лица; Face Withdraw — перед выводом средств; Face API Key — перед созданием API-ключа; [Risk Removal](risk-removal.md) — снятие ограничения Risk Control.
- **Bybit:** Claim Rewards — получение наград на аккаунте.

После Face API Key ключ создайте в MEXC сами, не откладывая: если MEXC снова запросит проверку лица, понадобится новый заказ.

## Какой аккаунт подходит {#eligibility}

Аккаунт прошёл первичную верификацию через платформу, биржа сейчас требует выбранную проверку, и по аккаунту нет другой реверификации или активного заказа. На MEXC, если первичный слот отменён из-за непройденной за 12 часов проверки лица, доступна только Face Withdraw.

Платформа проверяет это бесплатно до оплаты; неподходящие аккаунты пропускаются с причиной и не оплачиваются.

## Как оформить {#create}

До 120 аккаунтов за раз, для каждого — свежие cookies и прокси.

Рабочий бот:

1. «🔄 Реверификация» → биржа → тип.
2. Отправьте прокси, по одному на аккаунт, и нажмите «▶️ Продолжить».
3. Пришлите файлы cookies (`.json`) в том же порядке и нажмите «✅ Я отправил все файлы».
4. Проверьте план с ценами и нажмите «✅ Подтвердить и оплатить».

Веб-версия: «Создать заказ» → «Реверификация» → биржа и тип → [аккаунты](upload.md) → «Проверить аккаунты» → «Создать N · $…».

Если баланса не хватило, оплаченные аккаунты уходят в работу, а остальные можно оплатить кнопкой «🔄 Повторить остаток» в течение 2 часов. Для Risk Removal нужны ещё [скриншоты депозитов](risk-removal.md#proofs).

## Цена

Зависит от того, как куплен исходный заказ:

- стандартный — розничная цена;
- оптовый — оптовая при активной [подписке](subscription.md), иначе розничная;
- командный — ваша цена за слот, одна на пакет, целиком уходит исполнителю; нужна активная подписка.

Risk Removal для всех стоит по рознице; командным аккаунтам и здесь нужна подписка. Точная сумма — в плане перед оплатой.

## Исполнитель и сроки

Слот закреплён за исполнителем первичной верификации и другим не передаётся. Если исполнитель вышел из вашей команды, [отмените слот](cancel-refunds.md#reverify) или верните исполнителя в команду.

Срока выполнения нет: через 24 часа можно запросить [отмену](cancel-refunds.md#reverify). Реверификации не замораживаются при окончании подписки.

## Чем заканчивается реверификация {#outcomes}

- **Пройдена** — слот выполнен.
- **«ℹ️ Проверка не потребовалась — средства возвращены»** — биржа уже не требует проверку, а ссылка не выдавалась. Если выдавалась — слот выполнен.
- **«🚫 Неправильная страна»** — полный возврат.
- **Биржа отказала**, например заблокировала аккаунт, — слот не закрывается, возврата автоматически нет, решает поддержка.
