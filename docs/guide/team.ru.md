# Своя команда

Своя команда — исполнители, которых вы пригласили лично. Они выполняют ваши командные заказы, а цену за слот назначаете вы сами. Управлять командой можно в рабочем боте [@kycportal_bot](https://t.me/kycportal_bot) («👨‍💻 Моя команда») и в веб-версии (экран «Продавцы»).

Собирать и настраивать команду можно без подписки, но командные заказы создаются только при активной [подписке](subscription.md). Пока подписки нет, участники команды не видят ваших заказов.

## Приглашение

У вас есть персональная ссылка-приглашение: исполнитель открывает её в Telegram и присоединяется к команде.

- В команде может быть до **100** участников.
- Ссылку можно перевыпустить — старая сразу перестаёт работать.
- Если участник, которого вы поставили на паузу, снова перейдёт по ссылке, пауза не снимется — вернуть его можете только вы.

## Настройки участника

Для каждого участника можно задать:

- **лимиты** — сколько слотов он может взять из одного заказа и сколько держать в работе одновременно (или без ограничений);
- **разрешённые страны** — по каким странам он может брать ваши заказы (по умолчанию — любые).

## Пауза и удаление

- **Пауза** — участник временно не видит и не берёт ваши командные заказы. Уже взятые слоты выполняются как обычно. Снять паузу можно только вручную.
- **Удаление** — участник больше не может брать ваши заказы, а текущая ссылка-приглашение перестаёт работать, чтобы он не вернулся по ней. Слоты, которые он уже выполняет, не отменяются.

## Командные заказы

Командный заказ видят только участники вашей команды — с учётом их лимитов и разрешённых стран. Исполнители из общего пула его не видят.

Как создать:

- в рабочем боте — «➕ Новый заказ» → «Для моей команды»;
- в веб-версии — «Создать заказ» → «Командный».

Вы выбираете биржу и страну — любую, не только из каталога, — указываете цену за слот и количество. Цена за слот целиком уходит исполнителю. Нужны активная подписка и хотя бы один активный участник команды.

## Авто-возврат слота {#idle-return}

Если участник взял командный слот и долго его не двигает, платформа может вернуть слот в пул, чтобы его взял другой участник:

1. после первого таймера участнику приходит предупреждение;
2. после второго таймера слот возвращается в пул вашей команды.

Таймеры настраиваются, а функцию можно выключить: «⚙️ Настройки» → «🔄 Авто-возврат слота» в рабочем боте или «Настройки» → «Авто-возврат слота» в веб-версии. Когда авто-возврат выключен, слот остаётся у участника до завершения или до истечения [дедлайна слота](lifecycle.md#deadline). Настройка действует только на командные заказы.

## Статистика

На странице команды видны число активных участников, количество слотов в работе, доля успешно пройденных слотов и общее число выполненных — по всей команде. Подробная аналитика по команде есть в веб-версии, в разделе «Аналитика».
