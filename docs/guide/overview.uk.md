# Огляд платформи

KYC Portal — верифікація (KYC) ваших акаунтів на криптобіржах. Ви купуєте верифікацію для потрібної біржі та країни й передаєте cookies і проксі акаунта. Виконавець із цієї країни проходить перевірку особи за посиланням, створеним усередині акаунта; даних для входу він не має.

Біржі: **Bybit**, **MEXC**, **KuCoin**, **BingX**. Країни та ціни — у каталозі.

На MEXC і BingX після KYC є другий етап — [MEXC](lifecycle.md#mexc-hold), [BingX](lifecycle.md#bingx). На BingX для нього потрібно переслати код із листа BingX.

## Де працювати

| Де | Для чого |
|---|---|
| Бот-магазин [@kyctrade_bot](https://t.me/kyctrade_bot) | Купівля за стандартними цінами, поповнення, реферальне посилання |
| Робочий бот [@kycportal_bot](https://t.me/kycportal_bot) | Завантаження акаунтів, хід виконання замовлень, оптові й командні замовлення, реверифікації, команда, підписка, код BingX |
| [Вебверсія](web.md) | Усе, що є в робочому боті, а також каталог, повна історія операцій, аналітика й вибір виконавців |
| [API](../api/index.md) | Ті самі дії за ключем; підключається безкоштовно через підтримку |

Баланс, замовлення й мова спільні для ботів і вебверсії.

## Терміни

- **Слот** — один акаунт у замовленні, із власним статусом.
- **Виконавець** («Продавці» в інтерфейсі) — людина, яка проходить перевірку особи за вашим слотом.
- **Реверифікація** — повторна перевірка акаунта, верифікованого через платформу.
