# Реверифікації

Реверифікація — повторна перевірка акаунта, уже верифікованого через платформу, коли біржа знову її вимагає. Її проходить виконавець первинної верифікації.

## Типи

- **MEXC:** Face Security — повторна перевірка обличчя; Face Withdraw — перед виведенням коштів; Face API Key — перед створенням API-ключа; [Risk Removal](risk-removal.md) — зняття обмеження Risk Control.
- **Bybit:** Claim Rewards — отримання нагород на акаунті.

Після Face API Key створіть ключ у MEXC самі, не відкладаючи: якщо MEXC знову запросить перевірку обличчя, знадобиться нове замовлення.

## Який акаунт підходить {#eligibility}

Акаунт пройшов первинну верифікацію через платформу, біржа зараз вимагає обрану перевірку, і для акаунта немає іншої реверифікації чи активного замовлення. На MEXC, якщо первинний слот скасовано через перевірку обличчя, не пройдену за 12 годин, доступна лише Face Withdraw.

Платформа безкоштовно перевіряє це до оплати; акаунти, що не підходять, пропускаються із зазначенням причини й не оплачуються.

## Як оформити {#create}

До 120 акаунтів за раз, для кожного — свіжі cookies і проксі.

Робочий бот:

1. «🔄 Реверифікація» → біржа → тип.
2. Надішліть проксі, по одному на акаунт, і натисніть «▶️ Продовжити».
3. Надішліть файли cookies (`.json`) у тому самому порядку й натисніть «✅ Я надіслав усі файли».
4. Перевірте план із цінами й натисніть «✅ Підтвердити та оплатити».

Вебверсія: «Створити замовлення» → «Реверифікація» → біржа й тип → [акаунти](upload.md) → «Перевірити акаунти» → «Створити N · $…».

Якщо балансу не вистачило, оплачені акаунти йдуть у роботу, а решту можна оплатити кнопкою «🔄 Повторити решту» протягом 2 годин. Для Risk Removal потрібні ще [скриншоти депозитів](risk-removal.md#proofs).

## Ціна

Залежить від того, як куплено початкове замовлення:

- стандартне — роздрібна ціна;
- оптове — оптова за активної [підписки](subscription.md), інакше роздрібна;
- командне — ваша ціна за слот, одна на пакет, повністю йде виконавцю; потрібна активна підписка.

Risk Removal для всіх коштує за роздрібною ціною; акаунтам із командних замовлень і тут потрібна підписка. Точна сума — у плані перед оплатою.

## Виконавець і строки

Слот закріплено за виконавцем первинної верифікації, іншому він не передається. Якщо виконавець вийшов із вашої команди, [скасуйте слот](cancel-refunds.md#reverify) або поверніть виконавця в команду.

Строку виконання немає: через 24 години можна запросити [скасування](cancel-refunds.md#reverify). Реверифікації не заморожуються після закінчення підписки.

## Чим закінчується реверифікація {#outcomes}

- **Пройдено** — слот виконано.
- **«ℹ️ Перевірка не знадобилася — кошти повернено»** — біржа вже не вимагає перевірки, а посилання не видавали. Якщо видавали — слот виконано.
- **«🚫 Неправильна країна»** — повне повернення.
- **Біржа відмовила**, наприклад заблокувала акаунт, — слот не закривається, автоматичного повернення немає, вирішує підтримка.
