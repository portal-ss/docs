# Обзор платформы

KYC Portal — верификация (KYC) ваших аккаунтов на криптобиржах. Вы покупаете верификацию нужной биржи и страны и передаёте cookies и прокси аккаунта. Исполнитель из этой страны проходит проверку личности по ссылке, созданной внутри аккаунта; данных для входа у него нет.

Биржи: **Bybit**, **MEXC**, **KuCoin**, **BingX**. Страны и цены — в каталоге.

На MEXC и BingX после KYC есть второй этап — [MEXC](lifecycle.md#mexc-hold), [BingX](lifecycle.md#bingx). На BingX для него нужно переслать код из письма BingX.

## Где работать

| Где | Для чего |
|---|---|
| Бот-магазин [@kyctrade_bot](https://t.me/kyctrade_bot) | Покупка по стандартным ценам, пополнение, реферальная ссылка |
| Рабочий бот [@kycportal_bot](https://t.me/kycportal_bot) | Загрузка аккаунтов, ход заказов, оптовые и командные заказы, реверификации, команда, подписка, код BingX |
| [Веб-версия](web.md) | Всё, что в рабочем боте, плюс каталог, полная история операций, аналитика и выбор исполнителей |
| [API](../api/index.md) | Те же действия по ключу; подключается бесплатно через поддержку |

Баланс, заказы и язык общие для ботов и веб-версии.

## Термины

- **Слот** — один аккаунт в заказе, со своим статусом.
- **Исполнитель** («Продавцы» в интерфейсе) — человек, который проходит проверку личности по вашему слоту.
- **Реверификация** — повторная проверка аккаунта, верифицированного через платформу.
