# Исполнители и распределение заказов

Верификацию на бирже проходят реальные люди — исполнители (в интерфейсе — «Продавцы»). Исполнитель проходит проверку личности по ссылке, которую платформа формирует внутри вашей сессии. Данных для входа в ваш аккаунт у него нет.

## Подтверждённая страна

При регистрации исполнителя платформа сверяет страну его номера телефона с его фактическим местоположением. Если они совпадают, исполнитель получает подтверждённую страну. Поэтому ваши заказы выполняют люди, которые действительно находятся в стране заказа, — это повышает шанс пройти будущие реверификации по аккаунту.

## Как заказ находит исполнителя

Стандартные и оптовые заказы распределяются между местными исполнителями с подтверждённой страной заказа:

1. Сначала заказ видят ваши **приоритетные** исполнители из этой страны.
2. Затем — все исполнители с подтверждённой страной заказа.

Заблокированные вами исполнители ваших заказов не видят.

Командные заказы видят только участники [вашей команды](team.md). Реверификацию получает только исполнитель, который проходил первую верификацию аккаунта (см. [Реверификации](reverify.md)).

## Контроль качества

Платформа следит за тем, как исполнители справляются с реверификациями. Если доля успешных реверификаций у исполнителя опускается ниже допустимого уровня, он автоматически перестаёт получать новые заказы из общего пула. Уже взятые им слоты и закреплённые за ним реверификации это не затрагивает.

## Приоритет и блокировка

В веб-версии на экране «Продавцы» есть раздел «Маркетплейс»: в нём исполнители, которые недавно выполняли ваши заказы, а также те, кому вы уже поставили приоритет или блокировку. По каждому видна только ваша собственная история с ним — сколько слотов он выполнил и какая доля прошла успешно. Общего рейтинга исполнителей платформа не показывает.

| Действие | Что делает |
|---|---|
| «В приоритет» | Исполнитель первым видит ваши будущие заказы в своей подтверждённой стране. Доступно только для исполнителей с подтверждённой страной |
| «Убрать» | Снимает приоритет |
| «Заблокировать» | Исполнитель больше не видит ваши заказы из общего пула. Уже взятые слоты и командные заказы это не затрагивает |
| «Разблокировать» | Снимает блокировку |

!!! note
    Приоритет и блокировка доступны только в [веб-версии](web.md).
