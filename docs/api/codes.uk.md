# Статуси й коди

## Статуси слота {#slot-statuses}

Поле `status` слота й події `slot_status`.

| Значення | Що означає |
|---|---|
| `FREE` | Слот ніхто не взяв: порожній, завантажений або чекає виконавця після публікації |
| `IN_PROGRESS` | Виконавець узяв слот і проходить верифікацію |
| `PENDING` | Біржа розглядає верифікацію; строки на паузі |
| `VERIFICATION_FAILED` | Біржа відхилила спробу, виконавець повторює |
| `REUPLOAD_REQUIRED` | Потрібні свіжі проксі, cookies або і те, і інше; слот на паузі — [повторне завантаження](slot-actions.md#post-reupload) |
| `MEXC_HOLD` | MEXC: верифікацію пройдено, платформа чекає, чи не запросить біржа перевірку обличчя |
| `MEXC_FACE_REQUIRED` | MEXC запросила перевірку обличчя, виконавець проходить її без доплати |
| `BINGX_FACE_OFF` | BingX: KYC пройдено, триває другий етап — вимкнення входу за обличчям |
| `BINGX_REVIEW` | BingX: KYC пройдено, але завершити автоматично не вдалося; слот перевіряє підтримка |
| `RISK_AWAITING_DOCUMENT` | Risk Removal: готується апеляція |
| `RISK_SUBMITTED` | Risk Removal: апеляцію подано в MEXC |
| `RISK_FACE_EXPIRED` | Risk Removal: перевірку обличчя потрібно пройти ще раз, це робить той самий виконавець |
| `RISK_REJECTED` | Risk Removal: MEXC закрила заявку, не знявши обмеження; подальші кроки вирішує підтримка |
| `RISK_ERROR` | Risk Removal: із заявкою виникла проблема, нею займається підтримка |
| `COMPLETED` | Слот виконано |
| `CANCELLED` | Слот закрито; чому — у [`close_reason`](#close-reasons) |

## Статуси замовлення {#order-statuses}

Поле `status` замовлення, `order_status` слота й події `order_status`.

| Значення | Що означає |
|---|---|
| `PAID` | Оплачено, чекає завантаження акаунтів |
| `SESSION_UPLOADED` | Акаунти в усіх слотах, замовлення чекає публікації |
| `IN_PROGRESS` | Опубліковано, не всі слоти закрито |
| `COMPLETED` | Усі слоти виконано |
| `PARTIAL_COMPLETED` | Усі слоти закрито: частину виконано, частину скасовано |
| `CANCELLED` | Усі слоти закрито, жодного не виконано |

У дуже старих замовлень трапляються застарілі `ACCESS_GRANTED`, `IN_POOL`, `PARTIAL`, `REFUNDED`, `MANUAL`.

## Підсумок верифікації {#verification-results}

Поле `verification_result` слота. Регістр у значень різний — порівнюйте рядки як є.

| Значення | Що означає |
|---|---|
| `passed` | Пройдено |
| `pending` | Біржа ще розглядає |
| `wrong_country` | Неправильна країна |
| `blocked` | Біржа не допускає верифікацію на акаунті |
| `kyc_already_done` | Акаунт уже було верифіковано |
| `no_challenge_required` | Перевірка не знадобилася |
| `admin_cancelled` | Скасовано підтримкою |
| `DEADLINE_EXPIRED` | Сплив строк |
| `ACCOUNT_UNSERVABLE` | Біржа не приймає цей акаунт |
| `CLIENT_CANCELLED` | Скасовано вами |
| `failed`, `SUBSCRIPTION_LAPSED` | Застарілі, лише в старих слотів |

## Чого чекає від вас слот {#waiting}

Поле `waiting_for_client` слота — список. Непорожнє саме в тих слотів, які повертає `GET /slots?attention=true`.

| Значення | Коли | Що робити |
|---|---|---|
| `reupload` | Слот у статусі `REUPLOAD_REQUIRED` | Надішліть те, що вказано в `reupload_scope` (нижче) |
| `risk_proofs` | Потрібні нові скриншоти депозитів для Risk Removal | [Надішліть скриншоти](slot-actions.md#post-slot-risk-proofs) |
| `bingx_code` | Слот `BINGX_FACE_OFF` чекає код із листа BingX | [Надішліть код](slot-actions.md#post-bingx-code) |

`reupload` і `risk_proofs` бувають одночасно. Слот, який чекає повторного завантаження, чекає лише його — навіть якщо до цього просив код BingX.

Поле `reupload_scope` — що надіслати під час повторного завантаження:

| Значення | Що надіслати | Метод |
|---|---|---|
| `proxy` | Новий проксі | [`replace-proxy`](slot-actions.md#post-replace-proxy) |
| `session` | Свіжі cookies того самого акаунта | [`reupload`](slot-actions.md#post-reupload) |
| `full` | І cookies, і проксі | [`reupload`](slot-actions.md#post-reupload) |

## Що потрібно зробити {#actions}

Поле `action` події `slot_action_required`.

| Значення | Що означає | Що робити |
|---|---|---|
| `bingx_code` | BingX надіслав на пошту акаунта код для другого етапу | [Надішліть код](slot-actions.md#post-bingx-code) |
| `risk_proofs` | Потрібні нові скриншоти депозитів для Risk Removal | [Надішліть скриншоти](slot-actions.md#post-slot-risk-proofs) |

## Чому просять {#ask-reasons}

Поле `reason` події `slot_action_required` і `bingx.code_ask_reason` слота. На будь-який запит коду надсилайте код із найсвіжішого листа BingX.

| Значення | Що означає |
|---|---|
| `first` | Перший запит: KYC пройдено, BingX щойно надіслав код |
| `new_code_sent` | BingX надіслав код ще раз |
| `wrong_code` | Надісланий код не підійшов — перевірте його й надішліть знову |
| `wrong_code_resent` | Код знову не підійшов, BingX надіслав новий лист — перевірте кожну цифру |
| `worker_ready` | Виконавець готовий знову пройти перевірку обличчя, BingX надіслав новий код |
| `stale_resent` | Попередній код сплив (він діє близько 10 хвилин), BingX надіслав новий |
| `requested` | Лише для `action: "risk_proofs"`: запитано нові скриншоти |

`bingx.code_ask_reason` заповнене, лише коли `bingx.step` = `awaiting_code`, і не буває `requested`. Якщо запит відкрився, коли ваш час на коди вже закінчився, там `null`.

## Чому слот скасовано {#close-reasons}

Поле `close_reason` слота й `reason` події `slot_status` зі статусом `CANCELLED`. У відкритих і виконаних слотів, а також у слотів, закритих до появи причин, — `null`.

| Значення | Що означає |
|---|---|
| `wrong_country` | Країна документа не збіглася з країною замовлення, або акаунт ще до початку роботи було верифіковано в іншій країні |
| `blocked` | Біржа більше не допускає верифікацію на цьому акаунті |
| `already_verified` | Акаунт уже було верифіковано |
| `no_check_required` | Реверифікація: біржа не запросила перевірку, заради якої її замовлено |
| `slot_deadline` | Сплив строк виконання, обраний під час купівлі |
| `face_deadline` | MEXC: додаткову перевірку обличчя не пройшли вчасно |
| `bingx_face_off_failed` | BingX, другий етап: виконавець не встиг пройти повторну перевірку обличчя |
| `client_cancel` | Ви скасували самі |
| `admin_cancel` | Слот скасувала підтримка |
| `exchange_review_in_flight` | На біржі вже розглядається інша заявка щодо цього акаунта. Якщо вона не пройде, акаунт можна завантажити в нове замовлення |
| `exchange_attempts_spent` | На біржі вичерпано спроби верифікації на сьогодні. Завантажити акаунт у нове замовлення можна приблизно через добу |

## Види строків {#deadline-kinds}

Поле `kind` у `deadlines` слота. Строки впорядковано за зростанням `at`.

| Значення | Що означає |
|---|---|
| `slot_deadline` | Строк виконання, обраний під час купівлі |
| `budget` | Не пізніше цього моменту слот повернеться в пул, якщо виконавець не встигне ([час виконавця](../guide/sellers.md#worker-time)) |
| `mexc_hold` | MEXC: кінець вікна спостереження після KYC |
| `mexc_face` | MEXC: строк додаткової перевірки обличчя |
| `close_request` | Слот буде закрито в момент `at`; чому — у `reason` (нижче) |
| `client_cancel` | Коли буде перевірено ваше скасування реверифікації |

`close_request` і `client_cancel` зникають зі списку, коли їхній час минув. Інші строки можуть ненадовго залишитися після свого `at`.

## Чому заплановано скасування {#deadline-reasons}

Поле `reason` у `deadlines` слота; лише для `kind: "close_request"`, для інших — `null`.

| Значення | Що означає |
|---|---|
| `admin_cancel` | Скасування призначила підтримка |
| `slot_deadline` | Сплив строк виконання слота |
| `face_deadline` | Сплив строк перевірки обличчя на MEXC |

## Крок другого етапу BingX {#bingx-steps}

Поле `bingx.step`. Об'єкт `bingx` є в слота BingX із другого етапу, в інших слотів — `null`.

| Значення | Що означає |
|---|---|
| `requesting_code` | Платформа просить BingX надіслати код на пошту |
| `awaiting_code` | Чекаємо на ваш код — [надішліть його](slot-actions.md#post-bingx-code); ваш час іде |
| `checking_code` | Код перевіряється, зазвичай не довше за хвилину |
| `face_in_progress` | Код прийнято, виконавець проходить перевірку обличчя |
| `switching_off` | Перевірку обличчя пройдено, платформа вимикає вхід за обличчям |
| `waiting_for_worker` | Спроба виконавця не вдалася; коли він буде готовий, BingX надішле новий код |
| `under_review` | Слотом займається підтримка (статус `BINGX_REVIEW`) |
| `done` | Другий етап закінчено; підсумок — у `face_login` або `close_reason` |

Поки слот чекає повторного завантаження, `step` не змінюється, ваш час зупинено й код не приймається.

## Підсумок другого етапу BingX {#bingx-endings}

Поле `reason` події `slot_status` зі статусом `COMPLETED` у слота BingX і поле `bingx.face_login`.

| `reason` | `bingx.face_login` | Що означає |
|---|---|---|
| `bingx_face_login_off` | `off` | KYC пройдено, вхід за обличчям вимкнено |
| `bingx_face_login_left_on` | `left_on` | KYC пройдено, але вхід за обличчям залишився ввімкненим — наприклад, ваш час на коди закінчився |
| `bingx_face_login_unknown` | `unknown` | Слот завершила підтримка; чи вимкнено вхід за обличчям, платформа не перевіряла |

`face_login` — `null`, поки другий етап триває, і в скасованого слота. У слота, завершеного до другого етапу, немає ні об'єкта `bingx`, ні `reason` у події.

| Значення | Подія | Що означає |
|---|---|---|
| `bingx_code_accepted` | `slot_notice` | BingX прийняв ваш код. Пізніше код може знадобитися ще раз |
| `slot_frozen` | `slot_notice` | Слот повернувся від виконавця в заморожене замовлення: виконавцям його не пропонують, поки ви не поновите підписку або не скасуєте слот |

| `order_unfrozen` | `order_notice` | Підписку поновлено: заморожені слоти знову пропонуються виконавцям |

## Коди завантаження {#upload-codes}

### Файл не читається

Відповідь `422` (у `too_many_items` — `413`) на завантаження акаунтів, повторне завантаження й завантаження акаунтів масової реверифікації. `at` — номер акаунта (ваш номер із `positions` або номер профілю у файлі ADS Power), `profile` — ім'я профілю, `detail` — уточнення. Якщо проблем кілька, `issues` перелічує всі, а сама відповідь повторює першу.

| `code` | Що означає |
|---|---|
| `parse_too_large` | Файл завеликий для cookies одного акаунта (файл ADS Power — більший за 20 МБ) |
| `parse_too_many_cookies` | Cookies багатьох сайтів, а потрібні лише cookies біржі |
| `parse_cookie_value_too_long` | Не схоже на звичайний експорт cookies |
| `cookie_jar_too_large` | Cookies багатьох сайтів — біржа відхилить такий запит |
| `no_platform_cookies` | У файлі немає cookies потрібної біржі |
| `parse_unrecognized_format` | Це не cookies: скриншот, текст зі сторінки |
| `parse_empty_adspower` | У файлі ADS Power немає жодного профілю |
| `too_many_items` | Понад 200 профілів або рядків проксі (`limit`) |
| `parse_block_missing_cookie` | У профілі ADS Power немає cookies — у ньому не виконано вхід |
| `parse_no_proxies` | Немає жодного рядка проксі |
| `invalid_proxy` | Проксі не читається або схема не підтримується |
| `private_proxy` | Локальна чи внутрішня адреса, а не проксі |
| `parse_not_a_text_file` | Не текстовий файл |
| `parse_encrypted_export` | Експорт Cookie-Editor з паролем |
| `parse_har_file` | Запис мережевих запитів (HAR), а не cookies |
| `parse_broken_json` | Cookies пошкоджені: текст обривається або в ньому зайві символи |
| `parse_unsupported_cookie_export` | Цей формат cookies не читається (наприклад, команда cURL) |
| `parse_multiple_accounts_in_one_file` | Cookies кількох акаунтів в одному файлі |
| `parse_adspower_file` | Експорт ADS Power там, де потрібен файл cookies одного акаунта, — використайте `method=adspower` |
| `parse_empty_cookies` | Експорт порожній |
| `parse_wrong_exchange` | Cookies іншої біржі; `detail` — якої |
| `parse_wrong_site` | Cookies іншого сайту; `detail` — домен |
| `parse_not_logged_in` | У cookies немає входу в акаунт (MEXC, Bybit); `detail` може назвати домен, де вхід виконано |
| `parse_not_an_adspower_file` | Це не експорт ADS Power; `detail`: `cookies` — файл cookies, `proxies` — список проксі |
| `parse_export_without_cookies` | У жодному профілі немає cookies |
| `parse_block_has_two_profiles` | Два профілі злилися в один — зник рядок-роздільник. Експортуйте заново й не редагуйте |
| `parse_unsupported_proxy_type` | Тип проксі в профілі не підтримується: потрібен HTTP, HTTPS або SOCKS |
| `parse_proxy_has_spaces` | У рядку проксі зайвий текст або два проксі |
| `parse_proxy_no_port` | Не вказано порт проксі |
| `parse_proxy_non_latin` | У проксі не латинські літери |

### Акаунт не пройшов перевірку

Поле `error_code` в акаунтів у [`GET /orders/{order_id}/upload`](upload.md#get-upload). Ті самі коди приходять у відповіді `409` на зміну проксі й повторне завантаження; лише відсутність проксі там позначається `proxy_missing`, а не `missing_proxy`. Відхилений акаунт до слота не потрапляє.

| `code` | Що означає | Що робити |
|---|---|---|
| `proxy_auth_rejected` | Проксі не прийняв логін або пароль | Перевірте їх у провайдера проксі |
| `proxy_timeout` | Проксі не відповідає — наприклад, не оплачений або вимкнений | Перевірте проксі або надішліть інший |
| `proxy_bad_host` | Адресу проксі не знайдено | Перевірте адресу |
| `proxy_unreachable` | Не вдалося підключитися до проксі | Перевірте порт і тип (HTTP або SOCKS5) |
| `proxy_broken` | Проксі не працює | Надішліть інший проксі |
| `missing_proxy` | В акаунта немає проксі (наприклад, профіль ADS Power без проксі) | Вкажіть проксі; в ADS Power — додайте його в профіль і експортуйте заново |
| `exchange_unreachable` | Проксі працює, але біржа через нього не відкривається | Візьміть проксі іншого провайдера або міста |
| `session_invalid` | Біржа не пускає в акаунт за цими cookies — вхід застарів | Увійдіть заново, одразу експортуйте cookies і не виходьте з акаунта |
| `session_not_logged_in` | У cookies немає входу в акаунт (буває на KuCoin) | Увійдіть, експортуйте cookies і не виходьте з акаунта |
| `cookie_jar_too_large` | В експорті cookies багатьох сайтів | Експортуйте cookies лише на вкладці біржі |
| `identity_mismatch` | Це не той акаунт, що вже в слоті | Завантажте той самий акаунт |
| `duplicate_account_other_slot` | Акаунт уже в іншому слоті цього замовлення; `conflict_slot_id` — у якому | Використайте інший акаунт |
| `duplicate_account_other_order`, `duplicate_account` | Акаунт уже завантажено в інше замовлення | Використайте інший акаунт |
| `already_verified` | Акаунт уже пройшов верифікацію на біржі | Використайте інший акаунт |
| `verification_blocked` | Біржа більше не допускає верифікацію на цьому акаунті | Використайте інший акаунт |
| `verification_attempts_spent` | На акаунті закінчилися спроби верифікації на сьогодні | Завантажте його знову приблизно через добу або використайте інший |
| `verification_in_review` | Біржа вже розглядає заявку щодо цього акаунта | Дочекайтеся підсумку або використайте інший акаунт |
| `exchange_refused_unclear` | Біржа не дає почати верифікацію, причина невідома | Використайте інший акаунт; потрібен саме цей — напишіть у підтримку |
| `exchange_unreadable` | Біржа не відповіла | Завантажте акаунт знову через кілька хвилин |
| `slot_unavailable` | Поки тривала перевірка, слот узяли в роботу або закрили; нічого не змінилося | Повторіть за потреби |
| `slot_busy` | Слот зараз перевіряється | Повторіть через хвилину |
| `unknown_error` | Перевірка не завершилася | Повторіть через кілька хвилин; якщо повторюється — напишіть у підтримку |
